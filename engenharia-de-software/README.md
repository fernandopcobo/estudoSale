**Conteúdo conferido em:** 13/10/2026

A disciplina trabalha o **PDSL — Processo de Desenvolvimento de Sistemas Lean**, com a turma dividida em grupos, cada um responsável por uma disciplina do processo (trabalho dirigido apresentado na B1).

**Os 7 princípios do desenvolvimento Lean (página do curso):** eliminar desperdícios; construir com qualidade; amplificar o aprendizado; adiar comprometimentos; entregar o mais rápido possível; empoderar as pessoas; otimizar o todo.
